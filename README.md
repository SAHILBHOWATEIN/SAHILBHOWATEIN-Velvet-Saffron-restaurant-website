A responsive Indian &amp; Italian restaurant website built using HTML, CSS, JavaScript, and SASS.
# Velvet Saffron - Indian-Italian Fusion Restaurant

A professional, multi-page business website for a unique fusion restaurant.

## Features
- **Semantic HTML5:** Proper use of header, nav, main, section, and footer tags.
- **Modern CSS Layouts:** 
  - **CSS Grid** for main page structure and content sections.
  - **Flexbox** for navigation menus and smaller components.
- **SCSS/SASS:** Organized styling with variables, mixins, and modular files.
- **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
- **JavaScript Interactions:**
  - Mobile menu toggle.
  - Form validation for reservations.
  - Smooth scrolling for internal links.
- **Accessibility:** Proper heading hierarchy and alt text for images.
